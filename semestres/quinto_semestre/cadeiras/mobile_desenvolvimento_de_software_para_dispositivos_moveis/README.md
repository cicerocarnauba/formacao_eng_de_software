# Desenvolvimento de Software para Dispositivos Móveis (MOBILE)

[Voltar ao 5º Semestre](../../README.md)

## Ementa

Visão geral sobre dispositivos móveis: Comparação entre dispositivos de sensoriamento, celulares, tablets e computadores convencionais; Visão geral sobre as plataformas de desenvolvimento mais utilizadas, como Android SDK, Iphone SDK e Windows Mobile. Requisitos e desafios para computação móvel. Arquitetura de Software Móvel. Comunicação para Software móvel. Middleware e frameworks para Computação Móvel. Sensibilidade ao contexto e adaptação. Plataforma Android. Activities e Intents. Interfaces e Layouts. Services. Localização e Mapas. Sensores disponíveis.

## Conteúdo

- **`slides/`**: Slides das aulas 01 a 22b e questões de revisão (objetivas e subjetivas).
- **`trabalhos/`**: Especificações dos trabalhos práticos e roteiro de apresentação sobre autenticação.
- **`aulas/`**: Códigos práticos em JavaScript, Node.js e React Native / Expo:
  - `api-aula02`: API básica em Node.js.
  - `aula02` a `aula09`: Fundamentos de JavaScript e atividades de aula.
  - `aula10/meu-app` e `aula11`: Primeiros projetos em React Native / Expo.
  - `Exemplo-basico-de-navegacao`: Exemplo de navegação entre telas.
  - `aula18/mqtt-basico`: Comunicação com MQTT.
  - `aula19`: Prática em React Native / Expo.
  - `aula20/task-app`: Aplicativo de tarefas.
  - `aula21/sensor-app`: Aplicativo utilizando sensores do dispositivo.
  - `aula22/notas-app`: Aplicativo de notas.

> **Como executar os projetos Node/Expo:** as pastas `node_modules/` e `.expo/` não são versionadas. Entre na pasta do projeto desejado e execute `npm install` antes de iniciar.
