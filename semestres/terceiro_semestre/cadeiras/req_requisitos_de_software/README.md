# Requisitos de Software (REQ)

Bem-vindo ao repositório da disciplina **Requisitos de Software**.

## 📂 Estrutura do Diretório

Esta pasta contém ricas documentações, diagramas, trabalhos práticos e materiais bibliográficos sobre a engenharia de requisitos.

### 📝 Atividades Práticas
- Construção de Histórias de Usuário (User Stories).
- Análise de Aplicativo Concorrente.
- Ideação e Visão do Produto.
- Relatos e classificações de requisitos de software.

### 🎓 Projeto Final e Encontros Universitários (EU)
- **Logotipos**: Identidade visual para o projeto "Produtor+" (SVGs e PNGs).
- **Resumo Simples EU**: Templates, apresentações (ODP e PDF) e diagramas BPMN elaborados para os Encontros Universitários de 2025.

### 📚 Slides e Livros-Base
- **Slides**: Elicitação (Parte 1 e 2), Análise, Especificação, Validação, Requisitos Não-Funcionais.
- **Bibliografias e Guias**:
  - *Software Requirements (3rd Edition) - Karl Wiegers*.
  - *SWEBoK v3* e *BABOK*.
  - Templates de Documento de Requisitos e Processo.
