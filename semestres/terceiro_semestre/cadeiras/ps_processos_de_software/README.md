# Processos de Software (PS)

Bem-vindo ao repositório da disciplina **Processos de Software**.

Nesta cadeira, estuda-se o ciclo de vida do desenvolvimento de software, métodos ágeis e tradicionais, além da modelagem de processos corporativos.

## 📂 Conteúdo

### 📊 Slides de Aula
Coleção de PDFs sobre os principais processos e frameworks adotados na indústria:
- **Ágil e Lean**: Scrum, Kanban, Extreme Programming (XP).
- **Processos e Modelos Tradicionais**: RUP (Rational Unified Process), CMM e CMMI.
- **DevOps e Modelagem**: Palestras sobre DevOps e introdução à Modelagem de Processos.

### ⚙️ Diagramas BPMN
- Contém arquivos `.bpmn` (`Processos.bpmn`) desenvolvidos durante a prática de modelagem de processos.
