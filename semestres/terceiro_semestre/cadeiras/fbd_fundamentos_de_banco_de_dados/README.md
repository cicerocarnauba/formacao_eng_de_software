# Fundamentos de Banco de Dados (FBD)

Bem-vindo ao repositório da disciplina **Fundamentos de Banco de Dados**.

## 📂 Estrutura do Diretório

Este repositório contém todo o material teórico e prático desenvolvido ao longo do semestre:

### 🛠️ Atividades e Práticas SQL
- **Consultas Básicas e Avançadas**: Scripts SQL envolvendo a Casa dos Dragões, exercícios sobre personagens, entre outros.
- **Modelagem**: Diagramas ER (Entidade-Relacionamento) e esquemas relacionais exportados em `.png`.

### 🎓 Projeto da Disciplina (Trabalho Final)
- O projeto finalizado focado em **Eventos Culturais**, contendo:
  - Modelagem do banco (`Script.sql`, `script_de_inset.sql`).
  - Entregas em PDF do projeto passo-a-passo.
  - Relatório completo do projeto.

### 📚 Slides e Aulas
- **Modelo ER e EER**: Criação e mapeamento para relacional.
- **Modelo Relacional**: Criação de Tabelas em SQL.
- **Consultas**: Agrupamentos, Joins e Consultas Avançadas.
