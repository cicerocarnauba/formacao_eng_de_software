# Linguagens de Programação (LIP)

Bem-vindo ao repositório da disciplina **Linguagens de Programação**.

Nesta disciplina são abordados os diferentes paradigmas de programação, análise léxica e sintática, e a evolução das linguagens ao longo do tempo.

## 📂 Conteúdo

### 📚 Livros e Bibliografia Básica
- *Linguagens de Programação (Robert W. Sebesta - 11ª Edição - 2018)*
- *Linguagens de Programação (Allen B. Tucker, Robert Noonan - 2ª Edição)*

### 📝 Atividades e Trabalhos
- **Trabalho_LIP.pdf**: Descrição/Entrega do trabalho da disciplina.
- **Questões do Livro**: Resoluções de exercícios propostos nos livros-texto.
- **Listas**: Listas de exercícios teóricos e práticos.
