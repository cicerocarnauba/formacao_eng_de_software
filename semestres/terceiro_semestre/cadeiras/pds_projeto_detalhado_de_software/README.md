# Projeto Detalhado de Software (PDS)

Bem-vindo ao repositório da disciplina **Projeto Detalhado de Software**.

## 📂 Conteúdo

Este é um dos diretórios mais robustos, reunindo implementações em código e teoria avançada de design de software:

### 🧩 Slides e Materiais Teóricos
- **Princípios SOLID**: SRP, OCP, LSP.
- **Princípios GRASP**: Coesão, Acoplamento, Especialista, Criador, Invenção Pura, Indireção.
- **Padrões de Projeto (GoF)**: Builder, Factory, Observer, Iterator.
- **Conceitos**: Separação de Interesses e Encapsulamento.

### 💻 Códigos e Atividades Práticas
- **Simulador de Batalha Naval (Navio)**: Modelagem orientada a objetos com uso de interfaces e herança.
- **Simulador de Tribo Indígena**: Modelagem de Índios, Animais, Trocas e Cacique.
- **Chat Simples (Cliente-Servidor)**: Implementação de Sockets em Python e Java.
- **Desacoplamento UI/Lógica**: Laboratório focado em separar regras de negócio da interface.
- **Jogo Acerte o Número**: Implementação simples em Python (`jogo_acerte_num.py`).

### 🎓 Trabalho Final
- Diagramas de Classe e Diagramas de Sequência exportados em PNG e formato original (Astah).
