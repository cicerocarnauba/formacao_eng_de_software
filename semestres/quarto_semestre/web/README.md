# Desenvolvimento Web

Bem-vindo ao repositório da disciplina **Desenvolvimento Web**.

Esta pasta é focada puramente na camada de front-end (HTML, CSS e JavaScript), cobrindo desde os fundamentos básicos até manipulações de DOM e lógicas mais estruturadas.

## 📂 Estrutura do Diretório

A pasta foi reestruturada para garantir fácil navegação e separação de responsabilidades. Atualmente, os arquivos estão divididos da seguinte maneira:

### 📝 Atividades (`/atividades`)
Contém todos os exercícios práticos e entregáveis desenvolvidos ao longo da cadeira.
- **Exercícios de Sala**: Pastas contendo exercícios de aulas específicas, arquivos zipados de submissão, e comprovantes (`index.html`, `style.css`, `script.js`).
- **Exercícios de JavaScript (`js-atividade-01`, `js-exercicios-1`, `js-exercicios-2`)**: Coleções densas de scripts `.js` resolvendo problemas de lógica de programação e manipulação de DOM.

### 💻 Exemplos de Aula (`/exemplos-aula`)
- Códigos construídos durante as aulas juntamente com o professor.
- Exemplos de HTML puros (`exemplo.html`, `exemplo09-03-26.html`) e scripts isolados (`aula01.js`, `teste.js`).

### 📚 Slides e Material Teórico (`/slides`)
Material de apoio ricamente dividido por tecnologia:
- **Geral**: História da Internet, Redes e Protocolos e apresentação da disciplina.
- **CSS (`/css`)**: Propriedades, seletores, formatações visuais (Aulas 1 a 5).
- **HTML (`/html`)**: Tags HTML5 e Forms.
- **JavaScript (`/js`)**: Fundamentos da linguagem, eventos e atividades teóricas (Aulas 1 a 4).
