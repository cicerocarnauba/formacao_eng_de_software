# Lógica Matemática

Bem-vindo ao repositório da disciplina **Lógica Matemática**.

## 📚 Ementa
Lógica proposicional e de Primeira Ordem; Formalização de problemas; Sistemas dedutivos: axiomático, natural e tableaux; Correção e Completude. Lógicas Temporais para a Validação de Sistemas.

## 📂 Conteúdo e Cronograma

### 1. Introdução à Lógica para Computação

**Conteúdo:** Breve história da lógica; lógica simbólica; aplicações cotidianas da lógica.

**Materiais complementares:**
- A Brief History of Logic - Moshe Y. Vardi [PDF]
- Introdução à Lógica para Computação com Python - Davi Romero [GitHub]

### 2. Lógica Proposicional

**Conteúdo:** Linguagem da lógica proposicional; especificação de problemas; sistemas dedutivos; dedução natural; semântica, validade e satisfatibilidade; tableaux analíticos; o problema da satisfabilidade booleana (SAT).

- Linguagem da Lógica Proposicional
- Dedução Natural para a Lógica Proposicional
- Semântica da Lógica Proposicional

**Materiais complementares:**
- NADIA - Natural DeductIon proof Assistant
- Lógica Proposicional: Sistema de Dedução Natural no Estilo Fitch (YouTube)

### 3. Lógica de Primeira Ordem

**Conteúdo:** Linguagem da lógica de primeira ordem; especificação de problemas; semântica, validade e satisfatibilidade; dedução natural. 

- Linguagem da Lógica de Primeira Ordem
- Semântica da Lógica de Primeira Ordem
