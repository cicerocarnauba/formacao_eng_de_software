# Matemática Discreta

Bem-vindo ao repositório da disciplina **Matemática Discreta**.

## 📂 Conteúdo

Este é um dos repositórios mais completos, contendo desde notas manuscritas detalhadas até 9 listas de exercícios.

### 📝 Anotações (.sdocx)
Uma rica coleção de anotações feitas no Samsung Notes cobrindo as aulas teóricas e práticas, revisões para provas (AP2) e tópicos fundamentais:
- Revisão Básica de Lógica e Teoria dos Conjuntos
- Indução Fraca e Indução Forte
- Aritmética Modular e Divisibilidade
- Números Primos e Correções de Provas (AP1/AP2)
- Sequências e Somatórios

### 📚 Slides
